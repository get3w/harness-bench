# HB-04 比较与发布判定

- [x] 同 Harness 原生/集成按 suite/task/repetition 配对。
- [x] 模型、版本、环境、任务锁、预算、工具/权限/profile 等价校验。
- [x] 代理失败保留；基础设施/缺失样本明确不可比较。
- [x] 重复先按任务平均、10,000 次任务簇 bootstrap、95% CI、2% margin。
- [x] 小于 30 项证据不足；产品模式描述性；原创契约 fixture_only。
- [x] 原生均分描述输出；不把跨配置均分直接当排行榜。
- [x] 发布要求三种 Harness 通用质量通过、各自 11 个桌面场景通过。
- [x] 离线 HTML/JSON/JUnit；HTML 转义、桌面失败计入 JUnit。
- [ ] 【不依赖 Get3W 集成】三个 Harness 的真实独立能力任务原生重复运行和描述性比较。
- [ ] 【仅 OpenCode】同版原生/Get3W 能力配对统计结果与阶段验收记录。
- [ ] 【等待 Get3W 集成 DeepSeek】DeepSeek 同版原生/Get3W 能力配对统计结果。
- [ ] 【等待 Get3W 集成 Pi】Pi 同版原生/Get3W 能力配对统计结果。
- [ ] 【等待三 Harness 集成验收】三者完整配对与桌面证据的整体发布判定。

OpenCode 阶段验收与整体发布门禁分开记录。现有 CLI `release_verdict` 仍要求三者全部通过；
OpenCode 阶段不修改或绕过该门禁。原创任务只能验证集成闭环，不能给出能力非劣效通过结论。
- [ ] 校准真实样本量和统计功效；不把参数变体当独立任务。

非劣效不是证明绝对无损；结论只覆盖已测试版本、模型和任务分布。
